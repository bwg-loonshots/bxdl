# 통합 CLI UX 터미널 체험판

> 개발 중단 기록(2026-10-22): console 대신 직접 CLI를 우선한다. 이 체험판은 기존 메뉴 설계 참고용으로 보존하며 추가 개발하거나 새 CLI의 동작으로 안내하지 않는다. [현재 CLI 설계](../2026-10-22-cli-simplification.md)를 따른다.

`bxdl console` 완성 후의 핵심 조작을 미리 경험하는 **독립적인 설계 시안**이다. 실제 제품 명령은 아직 제공하지 않는다. 제품 CLI는 Rust로 구현하며 이 Python 데모는 제품에 포함하거나 연결하지 않는다.

## 실행

BXDL 저장소에서 Python 3로 실행한다. 추가 라이브러리·빌드·설치 패키지가 필요 없다.

```sh
python3 design/prototypes/integrated-operations-ux-demo.py
```

Mac Terminal, iTerm 또는 대화형 IDE 터미널에서 실행할 수 있다. 번호와 Enter로 선택하며 `:help`는 현재 입력 도움말, `:back`은 이전 화면, `:cancel` 또는 Ctrl-C는 체험 종료다. 변경 승인은 `y` 또는 `yes`만 허용하며 Enter는 거절한다. 일반 메뉴의 Enter는 표시된 안전한 기본 선택이다.

**모든 자료·검사·상태는 합성 예시다.** 실제 파일, 키, 네트워크, 엔진, launchd, 설치된 CLI를 읽거나 조작하지 않는다. 실제 경로·비밀번호를 입력할 필요가 없다. 상태는 메모리에만 유지되며 프로그램을 종료하면 사라진다. 실제 제품에서 제공할 디스크 저장·내구성 있는 이어하기와 다르다.

## 5분 체험 순서

| 체험 | 선택과 확인할 점 |
| --- | --- |
| 준비자료 | 홈 **1** → 자료 선택 전 **4**로 부족한 자료 안내 확인 → **1, 2, 3**을 차례로 눌러 예시 자료 선택 → **4**로 검사 |
| 한 항목 수정 | 설정 화면 **3** → `18181` → 다른 항목을 다시 묻지 않고 검토표로 복귀 → **9**로 설치 계획 확인 |
| 설치 승인 | 계획 **1** → 먼저 Enter로 거절 → 다시 **1** → `y`. 설치·등록만 완료하고 초기화/시작은 남는지 확인 |
| 초기화·시작 | 노드 관리 **2** → `y`로 초기화 → **2** → `y`로 시작. 요청 후 **1**로 로컬 READY 관측. 합의·정족수는 미확인 |
| 중지·재시작 | **2** → `y`로 중지 요청. 이때 시작 선택은 없음 → **1**로 정상 종료 확인 → **2** → `y`로 같은 데이터 재시작 |
| 이어하기 | 노드 관리 **0**으로 홈 → **2** → 내가 만든 설치 선택. 과거 기록은 보이지만 현재 미조회이며 **1**로 새로 확인 |
| 지원 | 노드 관리 **3**으로 정제 기록, **4**로 지원 보고서 미리보기. 실제 보고서 파일은 저장하지 않음 |

설치 전에도 **0**으로 홈에 나왔다가 **2**로 이어갈 수 있다. 홈에는 설정 검토 단계의 중단 예시와 운용 중인 노드 예시도 미리 준비되어 있다.

## 빠른 운용·문제 상황 체험

홈 **3**은 준비된 노드 관리, **9**는 문제 상황 선택이다. 문제 상황 메뉴는 데모 전용이며 실제 제품 메뉴가 아니다. 별도 예시 노드를 추가하므로 앞서 체험한 노드는 유지된다.

바로 운용 화면에서 시작하려면 다음 명령을 쓴다.

```sh
python3 design/prototypes/integrated-operations-ux-demo.py --scenario ready
```

`--scenario`의 값을 바꾸면 원하는 상황에서 시작한다. 각 화면은 **1**로 명시 조회한 뒤 행동한다.

| 값 | 체험할 상황 |
| --- | --- |
| `ready` | 현재 미조회 → 새로 확인 → 로컬 READY → 중지·종료 확인·별도 재시작 |
| `timeout` | 관측 시간 만료를 실패로 단정하지 않음. 다시 **1**을 누르면 **같은 시도**의 READY 예시를 관측하며 새 start는 하지 않음 |
| `unverified` | 정지 관측만으로 재시작하지 않음. **2**로 종료 확인 요청·승인 → **1**로 정상 종료 확인 뒤 시작 가능 |
| `unknown` | 이전 실행 결과 불명. 반복 조회로 해소하거나 자동 복구하지 않고 정제 보고서·지원 검토로 안내 |
| `mismatch` | 설치본과 현재 CLI 불일치. 읽기·지원만 가능하며 CLI 자동 실행/덮어쓰기 없음 |
| `changed` | 중지 확인에 `y`를 입력하는 동안 다른 CLI가 대상을 바꾼 예시. 기존 승인을 폐기하고 재조회 요구 |

관측 결과는 체험을 위한 결정된 시나리오다. 실제 관측 시간, 서비스 상태, 암호학적 검사, 잠금/동시성, 재개 내구성, 종료 증명을 구현하거나 검증한 것이 아니다. 지원 보고서도 화면 미리보기만 제공한다. 제품에서의 실제 저장·관측·서비스 실행은 후속 구현과 새 패키지 인수 범위다.

## 사용성 피드백

체험 중 다음 세 가지를 확인하면 후속 구현을 구체적으로 조정할 수 있다.

- 각 화면에서 현재 상태와 다음 행동을 설명 없이 고를 수 있는가?
- 번호/메뉴 이동과 반복 승인이 필요한 만큼만 있는가?
- 중간에 나간 뒤 이어하기, 중지 뒤 재시작, 오류 후 지원 경로가 예상대로 이어지는가?

이 데모는 화면·문구·동선 피드백용이다. UX-02~07의 제품 구현 완료나 사용성 인수 PASS 근거로 쓰지 않는다. 자동 검토를 위한 `--scripted`는 비TTY 입력을 허용하는 데모 전용 옵션이며 실제 BXDL CLI 계약이 아니다.
